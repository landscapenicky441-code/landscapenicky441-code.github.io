About

whoami

I’m Liu Xiang — an independent security researcher working on authorized bug bounty testing, whitebox source-code audit, and AI/LLM agent security.

My day-to-day is coordinated vulnerability disclosure under explicit rules of engagement: recon and attack-surface analysis for in-scope assets, access-control and business-logic testing, injection-class verification, and writing clear remediation reports for asset owners.

Focus areas

  • Web Application Security — access control / IDOR, injection (SQLi/SSTI/SSRF), business-logic flaws, request smuggling, cache poisoning, OAuth/auth chains.
  • AI Agent Security — prompt injection, MCP tool-surface abuse, agent-to-agent (A2A) trust boundaries, RAG / embedding attacks, insecure LLM output handling, ML supply-chain.
  • Code Audit — whitebox source review across Java / Python / Go / PHP / JS-TS, taint tracing from source to sink, and framework-specific sink libraries.

How I work

  • In-scope only — formal bug bounty programs or written authorization.
  • Minimal, non-destructive PoC — at most a few sample records to prove reachability; never mass extraction.
  • PII redacted in every output; no ransomware, no data exfiltration at scale, no DoS, no out-of-scope targeting.
  • Tooling assists (threat modeling, PoC drafting, report generation) but findings are verified by hand before reporting.

Everything published on this blog covers intentionally-vulnerable practice labs (PortSwigger Web Security Academy, etc.) and general, already-public technique. No undisclosed client or program findings appear here.
